JOTWELL — how to install on your iPad

1. Put this whole folder on a free web host. Easiest options:
   - Netlify Drop (app.netlify.com/drop): drag this folder onto the page. You get a link like https://something.netlify.app
   - GitHub Pages: create a repo, upload these files, enable Pages in Settings.
   The app must be served over https for install and offline mode to work.

2. On the iPad, open the link in Safari.

3. Tap Share (the square with an arrow) → "Add to Home Screen" → Add.

4. From now on, open Jotwell from its home-screen icon. Notes are saved on the
   iPad, it works offline, and Safari's storage cleanup doesn't apply to installed apps.

Optional: the View tab still has Backup / Restore if you ever switch devices.
